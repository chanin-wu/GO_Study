1. 初始化这个项目/模块

```bash
go mod init [模块名称]
go mod tidy 依赖治理 ，自动下载依赖，自动删除未使用的依赖
```

> 模块的名称：公开的 私有的

- 公开的 github.com/用户名/仓库名
  go get github.com/用户名/仓库名
  import ( "github.com/用户名/仓库名" )

- go语言 运行机制
  1. 和文件名称 main.go 无关
  2. 只要有一个 main 函数，就可以运行
  3. 大写开头的函数 和 变量，才能被外部调用
  4. 小写开头的函数 和 变量，只能在当前包内调用
  5. 同一目录下的包名，必须一致，go 语言强制的规则

- architecture\shopping> go run ./main

- cmd、internal、pkg 简单目录结构
  hello-mod/
  ├── go.mod
  ├── cmd/
  │ └── hello/
  │ └── main.go # 可执行入口：go run ./cmd/hello
  ├── internal/
  │ └── auth/
  │ └── auth.go # 仅本模块能导入（编译器强制）
  └── pkg/
  └── greeter/
  └── greeter.go # 可被外部模块导入的库代码
